# Tinute architecture and performance audit

Date: 2026-10-06

## Scope and evidence

Initial static audit of file admission, pipeline execution, all codec adapters, worker scheduling, result storage, previews/comparison, React subscriptions, downloads/ZIP export, and performance verification. The table records pre-redesign findings and source locations. Implementation and measured evidence are recorded in `performance-redesign-verification.md`. Their contribution to the reported crash remains unmeasured. The user's exact 7372×4392 input and device were not benchmarked.

## Required product contract

- Default output policy is `preserve`: resolve each job's output from its detected source format, not its filename or sampled content category.
- JPEG stays JPEG, PNG stays PNG, WebP stays WebP, and mixed batches preserve each file independently. Preserve `.jpg`/`.jpeg` spelling when appropriate for downloads; both identify JPEG.
- Conversion occurs only after an explicit output selection. Reset restores preserve-format behavior.
- Replace the current default `auto` setting and the UI's “Automatic” option with “Keep original format.” Do not reinterpret a persisted explicit conversion choice as preserve.
- The planner must receive source format and capabilities before decoding. Classification may adjust compression settings, never output format in preserve mode.
- An explicit conversion cannot fall back to a different format merely because it is smaller. Report the size outcome while honoring the conversion.
- Unsupported same-format encoding keeps the original with an accurate explanation, provided required privacy handling is possible. Otherwise report unsupported processing before decode. Never report an unchanged file as optimized or silently convert it.
- Animation, pages, bit depth, orientation, color appearance, and transparency are separate preservation requirements. Reject unsupported transformations rather than flattening content silently.
- Exact lossless JPEG requires a compressed-domain route or retaining the original. Quality 95 re-encoding is not lossless.
- Privacy handling must remain effective on every fallback. Retaining an original cannot bypass requested stripping.

## Recommended subsystem boundaries

1. **Inspector:** bounded header reads; detected format, dimensions, animation/pages, metadata, and capabilities.
2. **Planner:** immutable per-job settings; preserve-format resolution; native, direct-container, or WASM route; estimated resource costs; deadlines.
3. **Global scheduler:** reserve memory before reads; one large job initially, at most two small jobs; coordinate processing, previews, and export; no independently expanding batch queues.
4. **Worker executors:** bitmap-native JPEG/WebP; compressed-domain/container optimization where supported; isolated WASM codecs for other formats and advanced effort. Every executor owns and disposes its resources.
5. **Result repository:** File/Blob/stream interface, quota-aware OPFS, capped memory fallback, scoped cleanup, and transactional result publication.
6. **Preview service:** small thumbnails and viewport-sized comparison images; separately budgeted original-detail views; no base64 image encoding on the main thread.
7. **Export service:** direct File/Blob downloads and ZIP streams with destination backpressure, cancellation, and bounded fallback.
8. **Measurement:** per-stage timings, chosen route, retries, queue wait, cancellation latency, and memory measurements in benchmark runs. No image contents or personal metadata in diagnostics.

## Route policy

| Source    | Preserve-mode route                                                                                                                                                                                                                                                                                                                                                                                                                         |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JPEG      | Native JPEG for default lossy optimization; compressed-domain optimizer or original retention for exact lossless.                                                                                                                                                                                                                                                                                                                           |
| PNG       | Unchanged PNGs up to 4 MP use single-thread OxiPNG level 1. Larger PNGs validate and recompress filtered scanlines with native streaming inflation and fflate level 1, without RGBA expansion. Compression effort is time-boxed to four seconds; complete sanitized input is retained when effort runs out, after scanline validation. Pixel transformations reserve the higher decode/transform budget. No silent lossy palette reduction. |
| WebP      | Native lossy WebP when lossy optimization is allowed; WASM lossless only when requested or required by the preservation contract.                                                                                                                                                                                                                                                                                                           |
| GIF       | Preserve indexed palette and frame semantics. Current animation processing is unsupported; retain safely or report unsupported.                                                                                                                                                                                                                                                                                                             |
| AVIF/JXL  | Same-format WASM with bounded effort and memory. These routes have separate latency targets and may retain the original if safe optimization cannot fit the budget.                                                                                                                                                                                                                                                                         |
| TIFF      | Preserve pages and bit depth; current first-page RGBA8 decode is insufficient for general same-format optimization. Restrict support rather than silently flatten.                                                                                                                                                                                                                                                                          |
| BMP       | Preserve BMP; retain when no smaller equivalent representation is supported.                                                                                                                                                                                                                                                                                                                                                                |
| SVG       | Vector-preserving optimizer; until available, retain safely or report unsupported. Rasterization requires explicit conversion.                                                                                                                                                                                                                                                                                                              |
| HEIC/HEIF | No same-format encoder exists in this repo. ## Delivery order and validation

1. Establish preserve-format and transformation contracts, including explicit-conversion fallback tests.
2. Remove oversized default scoring/retries; add native JPEG route and direct PNG route.
3. Replace per-submission read-ahead with global memory admission and worker lifecycle management.
4. Replace full-source thumbnails, main-thread exotic previews, ArrayBuffer-only storage, and ZIP accumulation.
5. Bound GIF/color-transform work, repair native ownership, narrow React subscriptions, and expand performance gates.

Test mixed-format submissions, successive overlapping submissions, failed storage/quota, missing OPFS, cancellation during read/decode/encode/export, repeated compare/download operations, malformed headers, wide-gamut/oriented/translucent images, and repeated large-image runs.

For native JPEG/WebP default processing, initial proposed targets on a recorded reference laptop are median ≤5 seconds and p95 ≤8 seconds for the 7372×4392 case, usually one full encode, and <512 MiB incremental browser-process memory. These are targets requiring measurement, not guarantees. PNG and advanced formats need independently measured budgets; no universal five-second promise. Preserve dimensions and compare output quality before interpreting savings.

Run cold/warm production-build browser benchmarks in addition to typecheck, lint, tests, build, and bundle-budget checks. JavaScript heap metrics alone miss bitmap, native codec, and WASM allocations; measure browser-process memory externally in the benchmark harness. Existing unit tests or a passing initial bundle budget do not establish production performance.
